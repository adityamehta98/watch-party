# Synchronization benchmark

The README badge is generated by the same adaptive tuning function used by the browser player. It reports absolute player-to-room timeline error over a deterministic, reproducible simulation—not internet ping and not a hand-entered claim.

The harness runs eight concurrent viewer profiles (wired desktop, Wi-Fi laptop, Wi-Fi iPad, and mobile iPhone) for 72 simulated minutes. It exercises 200 ms correction ticks, measured RTT and jitter, clock-estimation noise, oscillator drift, buffer pressure, random stalls, rate corrections, hard seeks, and Safari-style periodic nudges. The first 10 seconds of each run are warm-up; every later sample, including stalls and recovery, contributes to the percentiles.

Run it with:

```powershell
npm run benchmark:sync
```

This updates [`results.json`](results.json) and the badge. `npm test` regenerates the measurement in memory and fails if either committed artifact is stale. Because this is controlled simulation rather than a field study, it is useful for regression comparisons; real results still depend on the devices, browser, network, and streaming provider.
